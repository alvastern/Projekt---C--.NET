# Renoveringskalkylator
I denna projektuppgift har jag valt att göra en webbapplikation där användare kan räkna ut hur mycket material i form av färg, golv och takpanel som behövs till en renovering. Jag har använt mig av ASP.NET och Razor Pages för att skapa denna webbapplikation.

## Hur körs projektet
För att köra applikationen krävs .NET 10 SDK.

1. Klona detta GitHub-arkiv och öppna projektmappen.
2. Öppna en terminal i mappen där Renoveringskalkylator.csproj finns.
3. Starta applikationen med dotnet run
4. Öppna adressen som visas efter Now listening on: i webbläsaren.
